Third-party components / 第三方组件
==================================

1. DarkestDungeonSaveEditor — tools/DDSaveEditor.jar
   Author : robojumper
   Source : https://github.com/robojumper/DarkestDungeonSaveEditor
   License: MIT
   Redistributed unmodified. The license text shipped by its author is kept inside the
   jar (META-INF/LICENSE and META-INF/NOTICE). This tool only calls its command line
   to decode save files into JSON.

2. Apache-2.0 libraries bundled inside the same jar
   Apache HttpComponents, Apache Commons, Google API client libraries,
   RSyntaxTextArea and others. Their license and notice files remain inside the jar
   (META-INF/LICENSE, META-INF/NOTICE, META-INF/DEPENDENCIES).

3. tools/names.txt
   A list of 3046 internal identifier strings (for example "unmovable_helmet",
   "pew_large_A") extracted from the game and installed mods, used to resolve hashed
   IDs found in save files. Identifiers only — no dialogue, item descriptions, art
   or audio are included.

No files from Darkest Dungeon itself are redistributed here.
Darkest Dungeon is © Red Hook Studios. This is an unofficial fan-made tool.
